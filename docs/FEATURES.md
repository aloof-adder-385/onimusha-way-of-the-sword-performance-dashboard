# Onimusha Way of the Sword Performance Dashboard — feature reference

A performance dashboard workspace for Onimusha Way of the Sword, built around graphics groups and test sessions, with frame pacing notes kept in a separate reference area.

| Section | Description |
|---|---|
| Graphics groups | Display or performance-related options, with space for configuration and comparison information. |
| Test sessions | Session and activity information grouped by the task or context it belongs to. |
| Frame pacing notes | Display or performance-related options, with space for configuration and comparison information. |

The project page follows the same section structure.
